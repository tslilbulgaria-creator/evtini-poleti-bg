# Евтини Полети — סורק דילים

הסורק רץ כל חצי שעה ב-GitHub Actions. בכל ריצה הוא מושך מחירים מ-Travelpayouts לכל שדות התעופה בבולגריה (SOF, PDV, VAR, BOJ), מזהה מחירים נמוכים משמעותית מהרגיל, ומפרסם אותם בערוץ הטלגרם ‎@evtini_poleti_bg (ובפייסבוק, אחרי שנחבר אותו).

## מה נחשב דיל
- מחיר שנמוך ב-40% או יותר מהמחיר הרגיל של הקו, וגם חוסך לפחות 15 €, **או**
- כל טיסה לכיוון אחד ב-19 € או פחות.
- טיסות שיוצאות בעוד פחות מ-3 ימים לא נכללות.

## הגבלות פרסום
- עד 8 פוסטים ביום, ועד 2 פוסטים בכל ריצה.
- פרסום רק בין 08:00 ל-22:00 שעון סופיה.
- אותו קו לא יפורסם שוב בתוך 4 ימים, אלא אם המחיר ירד ביותר מ-10% נוסף.
- אם מוגדר מפתח SerpApi, כל דיל נבדק בזמן אמת מול Google Flights לפני הפרסום.

את כל המספרים אפשר לשנות בקובץ `scanner/config.py`.

## הגדרה ראשונית
1. יוצרים מאגר (repository) חדש ב-GitHub ומעלים אליו את כל הקבצים.
2. נכנסים ל-**Settings → Secrets and variables → Actions → New repository secret** ומוסיפים:

| שם | ערך |
|---|---|
| `TP_TOKEN` | ה-API token מ-Travelpayouts |
| `TP_MARKER` | `400696` |
| `TG_BOT_TOKEN` | הטוקן של הבוט מ-BotFather |
| `TG_CHANNEL` | `@evtini_poleti_bg` |
| `SERPAPI_KEY` | (רשות) מפתח מ-serpapi.com |
| `FB_PAGE_ID`, `FB_PAGE_TOKEN` | (בהמשך) לפרסום בפייסבוק |

3. בדיקה: נכנסים ל-**Actions → Scan flight deals → Run workflow**, כותבים `test` ומריצים. אמורה להופיע הודעת בדיקה בערוץ.
4. אחרי זה מריצים עם `dry`. הסורק ירוץ בלי לפרסם, וביומן (log) יופיעו הדילים שהוא מצא.
5. מכאן הסורק רץ לבד כל חצי שעה.

**חשוב:** את הטוקנים שומרים רק ב-Secrets, אף פעם לא בתוך הקבצים עצמם.
